欢迎来到 **GuXingChen Blog**。

这里是我的数字自留地——一个用来记录技术、ACGN 和生活碎片的地方。我叫顾星辰，平时喜欢折腾代码、看番、玩游戏，也喜欢把一些零散的想法写下来。这个站点，就是这些想法最终落脚的地方。

## 这个站点长什么样

整体是清爽的浅色风格，主题色选了淡蓝。导航栏则刻意保持黑白：一边是蓝白相间的 GXC 几何字标，一边是干净的文字菜单。浏览器角标做成了科幻风的 **Cyber X**——深空底色、六边形 HUD、发光的 X 和星芒核心，算是给这个小小的数字空间加了一点“星际终端”的味道。

首页的背景图会随机切换：桌面端和移动端各有自己的图库，刻晴、纳西妲、椿会轮流出现。每次刷新都可能有不一样的画面，算是给日常访问留一点小惊喜。

侧边栏里有个人卡片、公告、分类和标签，右侧是站点统计和日历。亮色、暗色模式都支持，手机和平板上也会自动调整布局。

## 你会在这里看到什么

这个站点没有给自己设太窄的边界，大致会写三类内容：

- **技术笔记**：开发过程中遇到的问题、工具使用、代码片段，以及一些“原来还能这样”的小发现。
- **ACGN**：动画、游戏、角色和相关的感想。可能是一点考据，也可能只是单纯发发厨。
- **生活随笔**：不一定有用，但想留在互联网上的东西。

站点刚刚上线，文章会慢慢补。你可以从「关于我」开始认识我，也可以直接订阅 RSS，等下一篇文章出现。

## 这个站点是怎么搭的

整个站点是静态生成的，技术栈大致是：

```ts
const stack = ["Astro", "Svelte", "Tailwind CSS", "TypeScript"];
```

页面由 Astro 在构建阶段生成，交互部分交给 Svelte；搜索用 Pagefind 在本地建立索引，不需要额外的搜索服务。图片会在构建时做优化，文章支持 Markdown 和 MDX 两种写法。

为了让写作更顺手，站点还支持不少 Markdown 扩展：代码块、Mermaid 流程图、PlantUML、KaTeX 公式、提醒框、图片网格、GitHub 仓库卡片、Wiki Link，以及带密码的文章。想认真写长文的时候，也有文章系列、置顶和目录导航可以用。

> [!TIP]
> 本站支持亮/暗模式、全文搜索、RSS/Atom 订阅，以及 Markdown 的大部分扩展语法。之后我也会继续把这些能力用在真正的文章里。

## 一些我喜欢的细节

首页的随机壁纸、侧边栏的音乐播放器、文章底部的版权信息，还有那个会跟着主题色变化的小图标——这些都不是必需的，但它们让这个站点更像“我的地方”。

我希望它不只是一个展示页，而是一个可以长期写下去的地方：技术会更新，游戏会通关，生活也会继续，而这里会留下一些当时的记录。

如果你也在折腾自己的站点，或者只是想找个地方看看番、聊聊技术，欢迎常来。
